# Career Portfolio Design

## Goal

Create a separate, professional portfolio for hiring, while leaving the existing OneMaple personal blog prototype untouched.

## Audience and Positioning

The primary audience is Chinese hiring teams and technical interviewers, with a complete English toggle for international readers. Fengyi is positioned as a senior software engineer with backend and distributed-systems depth who can now ship AI products end to end. The site does not claim management or staff-level scope.

## Visual Direction

Use the approved first-prototype language: pale gray paper, ink-black text, restrained antique-gold accents, generous editorial whitespace, thin rules, Cormorant Garamond display type, Lora for English reading copy, and Noto Serif SC for Chinese copy. Avoid project-image galleries, dark technical dashboards, cards, gradients, logo clouds, and decorative metrics widgets.

## Page Structure

1. Header with Fengyi Zhang wordmark, anchors, language toggle, and resume/contact actions.
2. Hero with a large editorial statement, present-tense role description, and three evidence figures: 15,000+ satellites, 15M daily users, and 51% TP99 reduction.
3. Experience ledger with five roles, context, contribution, outcome, stack, and expandable detail bullets.
4. Selected project index with Type Machine, Time Machine, OnePoem, AmeBook, and OneFrame. Each row opens an internal case anchor and exposes real Live, GitHub, or Xiaohongshu links where available.
5. Skills index grouped by core engineering, AI/agent engineering, cloud/data, and frontend delivery.
6. Education and contact footer.

## Interaction and Accessibility

The bilingual switch preserves the information hierarchy. Project filters, expandable career rows, smooth section anchors, mobile navigation, keyboard escape handling, visible focus rings, and reduced-motion CSS are included. External links open in a new tab. No personal photography or private work is included in the job-focused site.
