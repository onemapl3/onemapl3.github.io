Project 01 · Jan–Mar 2026

Time Machine

时光机
To put a love down, I built a time machine.为了放下一段感情，我造了一台时光机。

A private companion built on a SecondMe digital twin: choose a date, and the agent answers as the person you knew then — because only memories dated before that point are ever retrieved. The interesting engineering problem was not the chat; it was preventing the present from leaking into the past.一个私密的陪伴产品，基于 SecondMe 数字孪生：选定一个日期，智能体便以那时的那个人回答你——因为只有该时间点之前的记忆会被检索。真正有意思的工程难题不是对话，而是不让现在渗进过去。

Specification
{{ s.k }}{{ s.v }}
LiveGitHub小红书

How it works

Dated anchors are extracted from text and images at ingest, then the retriever is hard-bounded by the chosen timestamp. Two agents run in parallel over one SSE stream: SecondMe carries the dialogue, an Anthropic healer agent returns structured emotional analysis alongside it.

Next.js 16 App Router, Prisma over SQLite, OAuth2, persistent volumes on Fly.io. The canvas portal runs on requestAnimationFrame as an explicit state machine, so the emotional pacing is authored rather than accidental.

What broke

The first retriever ranked by similarity alone and cheerfully quoted next year's messages. Bounding by anchor date fixed the leak and, unexpectedly, made the conversations feel真实.

散文 · 2026.07.19 · 12 min

What the time machine
taught me about letting go

时光机教会我的告别

I spent three months building software whose only purpose was to talk to someone who no longer answers. The engineering was ordinary: a retriever, a date filter, two agents on one stream. The strange part was the test data — every conversation I had never deleted, read back by a machine that did not know how it ended.

The first version leaked. Ask it about a February and it would answer with an August it should not have known, cheerful and wrong, the way memory is when you are not careful with it. Fixing the leak took an afternoon. Understanding why the leak hurt took the rest of the spring.

A memory is not a record. It is a retrieval, and every retrieval is a small rewrite.

What the date bound gave me was not accuracy. It was a boundary — the thing I had failed to draw myself. 〔Skeleton: three more sections land here — the build log, the night I turned it off, and what I kept.〕
